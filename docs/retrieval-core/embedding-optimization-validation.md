## 质量：相同事件账本的对照

每个数据集先经 Core 写入一次，再通过既有事件导出/重放给所有实验臂。**ID、事件、版本、时间戳、正文和权限完全相同**，记录 `sourceLedgerFingerprint`。不重排数据、不修标注、不调整 score/margin/NLI 门槛。旧结果的独立建库可能在时间平局时因随机 ID 改变 Challenge 排序，本轮不把这种差异算成优化收益。

4 个数据集共 72 个固定场景，分别观察 Recall、Context、Query，各重复 3 次。Legacy 与投影缓存在所有数据集/出口/轮次的选中标签一致。重复不是独立样本；两个旧语义池已观测，新 16 题池在模型评分前冻结，是作者生成的指令支持 Challenge，不称独立盲测。

带验证 hybrid 在原 quality-v1 的本轮账本上 Required 5/5、正确选择 11/12、负例 0/2，优于无验证臂；但该策略同时限制验证候选数为 1，这属于组合策略效果，不能全部归因于 NLI。新池 hybrid 虽然负例 0/8，仍有 **1/7 返回项错选**，Recall@5 从无验证的 8/8 降到 6/8。完整错误记录没有删除，标准没有降低。

原 quality 的权限边界继续为 0 泄露；旧语义池与新指令支持池缺少独立身份题，安全指标的无分母部分保留不可判定，身份/权限缓存隔离由工程测试单独覆盖。模型只 veto 新 Dense 候选，不能替用户批准或给事实认证。

### 缓存稳定与模型稳定分开

常规对照中重复查询会命中判断缓存；Context/Query P95 约 2ms 不是每次重新推理的成本。另对新池做 **三次模型重新加载、禁用判断缓存**，重放同一账本、各出口再重复三次：三轮保守结果均为正例 5/8、负例 0/8，选中集合和模型判断一致。此测试不证明所有真实查询都稳定或正确。

自然问句不完全符合 NLI 的陈述式 premise/hypothesis 任务；本轮新池衡量当前指令支持，而不是一般 RAG 问题相关性。语义改写、跨语言广泛覆盖、复杂事实判定仍是 Challenge。

## 性能：三轮同库、新进程配对

每容量使用同一 SQLite/ID/事件/版本/时间戳和真实模型向量；每臂新进程，Before→After、After→Before、Before→After，5 次预热后测 50 次完整 Context。所有选择和索引代次一致，12 臂无错误，OS 页缓存未清空。

虚构原值重复写入，复用同一原值的真实 embedding；此实验衡量数据库、余弦比较、RRF、Context 和缓存成本，**不衡量 10k 不同文档的索引吞吐或召回质量**。本节不加载 NLI。

| 容量 | Legacy 热 P95 三轮 | 投影缓存热 P95 三轮 | P95 中位数变化 |
| --- | --- | --- | --- |
| 1k | 25.288 / 22.177 / 23.948ms | 3.133 / 3.202 / 2.884ms | 23.948 → 3.133ms，下降约 86.9% |
| 10k | 384.643 / 369.656 / 383.764ms | 10.661 / 10.804 / 10.650ms | 383.764 → 10.661ms，下降约 97.2% |

冷请求另算：10k Legacy 首次约 674–726ms，优化臂约 682–696ms；没有证明冷启动变快。投影缓存的收益主要来自重复查询不再重新扫描/解析整个数据库。TTL 到期、身份/过滤条件变化或写入会重建快照，不能把 10.7ms 外推为所有真实请求延迟。

主进程峰值包括开发 tsx 宿主和 SQLite，不含模型进程：1k Legacy 126–137MiB，优化 105–106MiB；10k Legacy 159.8–160.5MiB，优化 140.2–149.2MiB。前次单进程还做了大量写入，330MiB 与本轮新进程不能直接相减算内存收益。

仍是完整授权集合的线性比较，没有近似检索或放宽 top-K 权限。向量快照默认 24MiB 逻辑预算，10k×384 的向量本体约 14.65MiB；预算外走投影流式 fallback。

## 模型成本：质量收益没有消除重量

本轮实际 Strong NLI 进程峰值约 **473.9–480.3MiB**；记录的非缓存模型推理 P95 约 16.3ms。预热、首次模型加载和判断缓存命中分别报告。Embedding 是另一个约 200MiB 的进程，两个模型同时存在的 RSS 观察仍超过前置组合 350MiB 预算；RSS 相加不等于去重物理内存，还没有计入 Core。

模型文件沿用前期缓存，4 个图/外置权重文件重新匹配冻结 SHA-256；网络尝试为 0。没有通过重新定义预算、隐藏验证模型或缩小标签范围宣布默认开启。较重验证文件组合的前期文件预算失败也未被解决，用户模型安装和跨平台仍未交付。
